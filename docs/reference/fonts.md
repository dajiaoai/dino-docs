# 字体支持

大角几何公开支持以下字体 `key`：

| 字体 `key` | 名称 | 说明 |
| --- | --- | --- |
| `sans-serif` | 无衬线字体 | 默认字体；由运行环境选择可用的无衬线字体 |
| `serif` | 衬线字体 | 由运行环境选择可用的衬线字体 |
| `monospace` | 等宽字体 | 由运行环境选择可用的等宽字体 |
| `Times New Roman` | 新罗马字体 | 优先使用 Times New Roman，并按运行环境回退 |

未使用自定义字体配置时，请只使用以上字体 `key`。通用字体族的实际字形可能因操作系统、浏览器或服务端渲染环境而不同；对字形和排版有严格要求时，应接入指定的自定义字体。

## 自定义字体

自定义字体的接入方式取决于使用场景：

| 使用场景 | 接入方式 |
| --- | --- |
| SDK 内嵌几何画板 | 由接入方在创建编辑或演示实例时通过 `fonts` 配置传入字体资源，详见 [SDK 自定义字体](../sdk/2/fonts) |
| MCP 服务 | 服务运行在大角几何服务端，无法由调用方在单次工具调用中直接传入字体文件；如需自定义字体，请[联系我们](../CONTACT)开通支持 |
| HTTP API | 智能生图与渲染运行在大角几何服务端，无法由调用方在单次请求中直接传入字体文件；如需自定义字体，请[联系我们](../CONTACT)开通支持 |

接入方应自行确认并处理自定义字体的使用许可和网络分发授权，确保使用方式符合相应字体的许可协议。
