# 尺寸单位与换算

当你在大角几何开放平台中设置字号、线宽或导出图片尺寸时，相关参数通常使用 `px`。如果你的设计稿、排版软件或印刷规范使用 `pt`，请先换算为 `px` 再传入。

::: tip 先看结论
- 设置字号、线宽、点或标记的显示大小：使用 px。
- 指定导出位图的宽度和高度：使用 px。
- 使用排版印刷规范中的 pt：换算为 px 后再填写参数。
- 设置几何坐标、几何长度或视野边界：使用画板逻辑坐标，不要做 px/pt 换算。
:::

## 设置视觉尺寸时使用 px

当你控制文字、线条或其他画板元素的显示大小时，请使用 **px（像素）**，例如：

- 文字的字号；
- 线条、边框和几何对象的线宽；
- 点、标记等对象的视觉尺寸；
- 导出位图的像素宽度和高度。

在 SDK、API、MCP 或工程文件中，这类字段通常接收数值。例如，字号字段的值为 `16` 时，请将它理解为 `16 px`，而不是 `16 pt`。除非对应的接口文档另有说明，请传入数值 `16`，不要传入 `"16px"` 或 `"12pt"` 这类字符串。

::: warning 不是所有数值都是 px
如果你正在设置几何点坐标、几何长度或画板视野边界，这些数值使用画板逻辑坐标，不是 px，也不需要换算为 pt。请在填写参数前，根据对应的接口文档确认字段表示的是“视觉尺寸”、“输出像素”还是“逻辑坐标”。
:::

## 在哪些能力中需要注意单位

| 当你使用 | 你可能需要设置 | 应如何处理 |
| --- | --- | --- |
| 内嵌画板与编辑器 | 字号、线宽、点和标记的显示大小 | 视觉样式填写 px 数值；iframe 容器宽高由你的宿主页面 CSS 控制 |
| SDK 与工程文件协议 | 画板对象的各类样式尺寸 | 样式尺寸填写 px 数值；点坐标和几何长度使用逻辑坐标 |
| API 渲染与图片导出 | 输出图片的宽高、图中的字号和线宽 | 固定输出宽高和返回的图片宽高使用 px；`viewBound` 等视野参数使用逻辑坐标 |
| MCP、REPL 与 AI 绘图 | 通过指令或工具设置的字号、线宽等样式 | 样式尺寸使用 px；数学图形的坐标和长度使用逻辑坐标 |
| 排版印刷 | 排版软件中的字号、线宽和成品物理尺寸 | 将 pt 换算为 px 后再填写大角几何参数；位图输出还需单独考虑 DPI |

## 如何理解 px

`px` 是网页和画板中常用的像素单位。你可以用它表达屏幕上的视觉大小，也可以用它指定位图的输出宽高。

需要注意，`1 px` 不等于某个固定的屏幕硬件像素，也不天然对应固定的纸面长度。设备像素比、浏览器缩放、画板相机缩放以及导出设置，都可能影响最终看到或输出的大小。

- 对于字号和线宽，px 表示标准视觉尺寸。
- 对于位图输出的 `width` 和 `height`，px 表示输出图片的实际像素数。
- 对于几何坐标和视野边界，数值不表示 px，它们会在渲染时根据画板缩放关系映射到像素。

## 使用 pt 时如何理解和处理

`pt`（point，点）是排版印刷领域常用的绝对单位，`1 pt = 1/72 in`。大角几何的尺寸参数不直接使用 pt，因此当你手头的设计稿或排版规范给出 pt 值时，请先按 CSS 绝对单位的标准比例转换：

```text
96 px = 72 pt = 1 in

pt = px × 0.75
px = pt × 96 ÷ 72 = pt × 4 ÷ 3
```

例如，印刷稿要求字号为 `12 pt`，换算后是 `16 px`，传给大角几何的字号参数应填写数值 `16`。

## 在接入参数中怎么填

当你在 SDK、API 或 MCP 数据中填写字号、线宽或其他视觉尺寸时，请先将手头的 pt 值换算为 px。下面是示意例，具体字段名以你正在使用的接口文档为准：

```json
{
  "fontSize": 16,
  "strokeWidth": 0.667
}
```

上述数值分别对应 `12 pt` 字号和 `0.5 pt` 线宽。

## 精度与印刷注意事项

- 建议协议数值保留 2～3 位小数；对细线宽不要过早取整，否则误差会很明显。
- px 与 pt 的换算解决的是尺寸参数口径问题。最终成品的物理尺寸还可能受导出、置入和打印时的缩放影响。
- 位图印刷还需要考虑 DPI。指定印刷尺寸时，所需像素数可按 `像素数 = pt ÷ 72 × DPI` 计算；这与协议中 px/pt 的尺寸换算是两个不同问题。
- 将导出结果置入排版软件后，请检查软件是否自动缩放，并以实际输出尺寸为准进行印前校样。
