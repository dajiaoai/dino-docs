# 内嵌编辑器 AI 绘图能力、API 与用量统计上线

- 类型：能力上新
- 发布时间：2026-06-29
- 生效时间：2026-06-29
- 影响范围：使用 SDK 编辑模式、内嵌 AI 绘图能力或开放平台 API 的开发者
- 是否需要操作：如需启用该能力，需要升级 SDK、接入内嵌模式 AI 生图 API，并在宿主后端完成请求转发和额度校验

## 变更内容

本次上线包含三部分：

1. **SDK 2.8.0 支持内嵌编辑器 AI 绘图**：内嵌编辑模式可以开启 AI 对话面板。用户在编辑器中发起 AI 绘图请求后，宿主页面监听 SDK 抛出的 `aiRequest` 事件，并通过 `editor.ai.consumeStream()` 将返回流交回编辑器处理。
2. **内嵌模式 AI 生图 API 上线**：宿主后端可以将编辑器生成的 AI 请求上下文原样转发给大角几何后端，由大角几何完成模型调用、几何指令生成和流式结果返回。浏览器前端不需要、也不应直接持有服务端 API token。
3. **控制台用量显示上线**：开放平台控制台已支持查看应用维度的 AI 调用用量和点数消耗，便于开发者做额度管理、账单核对和问题排查。

整体调用链路为：用户在内嵌编辑器中输入需求，SDK 发出 `aiRequest`，宿主后端完成用户鉴权与额度校验后调用大角几何 AI 生图接口，前端再把返回流交给 SDK，编辑器自动更新对话与绘图状态。

## 扣费机制

内嵌编辑器 AI 绘图本身由 SDK 桥接，实际扣费按大角几何后端产生的 AI token 用量结算。

| 环节 | 说明 |
| --- | --- |
| 扣费对象 | 调用大角几何开放平台 AI 能力的应用账户 |
| 扣费时机 | 只要请求产生了 AI token 用量，就会按实际消耗结算；失败、取消或断连不等于不扣费 |
| 扣费口径 | 按实际 token `usage × model` 对应价格计算 |
| 用量查看 | 可在开放平台控制台的应用详情中查看调用记录与点数消耗 |
| 宿主侧额度 | 宿主系统可以在自己的后端继续做用户额度、套餐、次数或风控限制 |

## 适用场景

- 在自己的产品中嵌入大角几何编辑器，并希望用户可以直接通过自然语言生成或修改几何图形
- 构建 AI 辅导、题目解析、教案生产、课件编辑等带有几何绘图能力的工作流
- 需要由宿主系统统一管理鉴权、计费、日志与风控边界

## 如何开始使用

1. 升级到 `@dajiaoai/algeo-sdk@2.8.0` 或更高版本。
2. 使用 `createEditor(...)` 创建内嵌编辑器，并传入有效的 `auth.appId`。
3. 在开放平台控制台完成应用配置，并准备服务端 API token。
4. 开启或保留默认的 `ui.aiChatPanel`。
5. 监听 `aiRequest` 事件，将 `payload` 原样发给宿主后端。
6. 宿主后端完成用户鉴权、额度校验后，调用大角几何内嵌模式 AI 生图 API。
7. 前端通过 `editor.ai.consumeStream()` 消费返回流。
8. 上线后在控制台查看应用用量与点数消耗。
