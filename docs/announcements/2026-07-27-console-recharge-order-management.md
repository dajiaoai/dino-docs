# 控制台充值与订单管理上线

- 类型：能力上新
- 发布时间：2026-07-27
- 生效时间：2026-07-27
- 影响范围：使用开放平台 API、MCP 等按点数计费能力的客户
- 是否需要操作：如需补充点数，可登录控制台进入「充值订购」自助购买

## 上线内容

开放平台控制台现已上线充值订购与订单管理系统，支持在线购买资源包或直接充值点数，并在支付后自动发放至当前客户主体的点数账户。

本次上线包括：

1. **资源包购买**：可根据调用规模选择资源包，享受对应的点数倍率；支付并到账后立即生效。
2. **点数直接充值**：按 `1 元 = 10,000 点` 充值，20 元起充；到账点数永久有效，适合临时补点和低频调用。
3. **微信扫码支付**：确认订单后可使用微信扫码完成支付，支付结果和点数发放进度会在页面同步更新。
4. **订单管理**：可按订单号、订单状态和订单类型查询记录，查看支付金额、创建时间、支付时间及到账状态。
5. **订单后续操作**：待支付订单可继续支付；已完成订单可查看资源包权益、点数到账记录和支付信息；异常订单可按页面提示联系支持。

## 如何使用

1. 登录[开放平台控制台](https://open.dajiaoai.com/console/dashboard)。
2. 在左侧导航进入「充值订购」。
3. 选择资源包或点数充值，确认订单后使用微信扫码支付。
4. 支付完成后，在「充值订购」查看可用点数，或进入「订单管理」查询订单和到账详情。

同一客户主体下的 API、MCP 调用共用一个点数账户。存在多个有效资源包时，系统优先抵扣较早到期的资源包点数；资源包点数不足后再抵扣永久点数。

## 注意事项

- 资源包有效期从点数到账时间开始计算，多个资源包可同时生效。
- 未支付订单将在倒计时结束后自动关闭。
- 当前支付渠道为微信支付。
- 当前暂不提供客户侧自助开票和退款入口，如有需要请联系支持。
