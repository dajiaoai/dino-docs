# 智能生图 API 服务调价：更强底模，更低成本

- 类型：计费调整
- 发布时间：2026-08-27
- 生效时间：2026-09-01
- 影响范围：使用智能生图 API 的开发者
- 是否需要操作：无需额外配置；新价格将在生效日自动应用

为让更多开发者和教育场景以更低门槛获得高质量的几何智能生图能力，智能生图 API 将于 **2026 年 9 月 1 日** 起正式下调价格。

本次价格调整同步伴随底模能力升级。升级后的模型在几何题图理解、复杂题目生成与参考图还原等核心任务上持续增强，帮助开发者以更低成本获得更可靠的生成结果。

## 调整后价格

> 智能生图 API 全线享受 7.5 折。

| 模型 | 调整后价格 |
| --- | ---: |
| `dinogeo-1` | **0.45 元 / 次** |
| `dinogeo-1-pro` | **0.60 元 / 次** |

新价格将于 9 月 1 日起自动生效，无需额外配置。

## 能力测评

以下数据来自大角几何内部评测。测试集覆盖初、高中几何题图约 2,000 道，以及复杂综合题与证明题约 500 道。

| 评测维度 | `dinogeo-1` | `dinogeo-1-pro` |
| --- | ---: | ---: |
| 标准几何题一次通过率 | 95% | 97% |
| 复杂综合题一次通过率 | 79% | 89% |
| 图片参考还原准确度 | 83% | 93% |
| 平均生成耗时 | 30.26 秒 | 51.64 秒 |

`dinogeo-1` 更适合高频、标准化的几何题图生成需求，在速度与成本之间取得良好平衡；`dinogeo-1-pro` 则面向复杂综合题、证明题及高保真参考图还原等场景，提供更高的生成成功率与还原精度。

> 说明：以上能力数据为内部测试结果，实际效果可能因输入内容、任务复杂度及调用环境不同而有所差异。

## 更适合规模化落地

无论是题库生产、智能讲题、作业系统，还是教辅内容创作，智能生图 API 都将以更低调用成本支持更大规模的应用落地。欢迎在 9 月 1 日后体验升级后的 `dinogeo-1` 与 `dinogeo-1-pro`。
