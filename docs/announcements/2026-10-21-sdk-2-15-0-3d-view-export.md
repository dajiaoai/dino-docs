# SDK 2.15.0：3D 固定视图与图片导出升级

- 类型：能力上新
- 发布时间：2026-10-21
- 生效时间：2026-10-21
- 影响范围：使用 SDK 内嵌编辑器、立体几何画板与图片导出的开发者
- 是否需要操作：使用新增能力需升级至 SDK 2.15.0；自托管内嵌页面需同步更新

SDK 2.15.0 重点新增 **3D 固定视图能力**，扩展 **3D 图片导出**。接入方可以为立体几何画板保存合适的展示视角，并按需要调整导出图片的投影、尺寸和截取范围，更方便地制作课件、题库与教学资料。

## 新增功能

### 保存 3D 固定视图，重复导出沿用同一视角

现在可以为 3D 画板保存一套固定视图，设置观察角度、缩放、投影方式、输出尺寸和截取范围。后续导出时可沿用这套配置，减少反复调整构图的操作。

固定视图与编辑时的观察视角分别保存。日常旋转、查看立体图形后，仍可使用预设视角导出图片，适合需要统一配图风格的课件与题库。固定视图支持启用、关闭，以及撤销、重做；关闭后仍保留原有配置。

![](https://luhuidev.oss-cn-beijing.aliyuncs.com/f737a40ea667abd2b84657d3.png)

### 3D 图片导出，支持更灵活的构图

导出立体几何图片时，可以选择正交、透视或斜投影，并调整视口尺寸与截取范围。既可以突出图形的空间关系，也可以截取需要的局部区域。

单次导出还可以临时覆盖视图配置，方便从同一画板输出不同角度或尺寸的配图。需要展示完整图形时，也可以使用完整内容导出模式，由图形范围决定构图。

![](https://luhuidev.oss-cn-beijing.aliyuncs.com/a7885c1d71e35255d7cad4e5.png)

### 创建空白 3D 画板，支持指令绘图

接入方可以直接创建空白 2D 或 3D 画板，方便把“新建立体几何”接入自己的产品流程。

编辑模式也新增了指令绘图能力，可通过指令创建和修改图形，并配合撤销、重做使用，适合批量构图或由应用自动组织绘图步骤。

![](https://luhuidev.oss-cn-beijing.aliyuncs.com/f2c7fad197bd86fef916ad72.png)

## 修正与改进

- **旧文件加载更方便**：支持的旧版文件会在加载时自动转换，减少接入方自行处理格式的工作。
- **初始内容加载更明确**：同时提供初始内容和分享文件时，优先使用初始内容，避免额外加载分享文件。
- **画板信息查询更完整**：接入方可以获取画板的 2D/3D 模式等信息，为不同画板提供对应的操作与导出入口。
- **示例更丰富**：补充 3D 固定视图、图片导出和指令绘图示例，便于体验新增能力。

## 升级说明

使用新增能力，请将 SDK 升级至 **2.15.0**。如果使用自托管的内嵌页面，也需要同步更新到支持这些能力的版本。
