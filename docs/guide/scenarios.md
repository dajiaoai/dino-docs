# 适用场景

数学几何能力是许多教育产品的核心基础，但自主研发一套复杂的几何画板系统往往面临极高的技术门槛。大角几何开放平台通过将底层能力解耦，能够适配以下典型业务场景。

## 1. 在线教育与智慧课堂

在数字化教学过程中，动态的几何演示能将抽象的数学逻辑直观化。

- **动态讲义嵌入**：在课程页面中直接嵌入交互式几何图形，支持教师进行动态演示，学生进行实时探索。
- **课件交互升级**：告别静态图片，让课件中的几何图形支持拖拽、参数联动与动画播放，提升课堂参与度。

## 2. 数字化题库与内容平台

为海量的数学题目提供低成本、高效率的配图方案。

- **结构化图形加载**：通过协议快速渲染几何图形，无需为每道题人工制作静态图片。
- **题目动态关联**：支持在习题中嵌入可交互的画板，允许学生在解题过程中通过动手操作来验证思路。

## 3. AI 智能辅导 (AI Tutor)

大角几何是 AI 原生的几何引擎，专门为大语言模型（LLM）与智能代理（Agent）设计了深度集成方案。

- **动态画图讲解**：AI 在讲解几何题时，可以自动调用接口在画板上实时作图，展示辅助线构造或图形变换过程。
- **智能交互诊断**：通过程序化接口实时获取学生在画板上的操作状态，辅助 AI 精准判断学生的解题薄弱点。

## 4. 教案与课件生产工具

赋能教研团队，提升数字化内容的产出效率。

- **画板组件集成**：教案工具可以直接内嵌编辑模式的画板，让老师在编写教案时快速生成专业的几何图形。
- **内容共享与流转**：基于标准化的结构化协议，实现几何内容在不同教研系统间的无缝传递与二次编辑。

## 5. 独立开发者与数学创新工具

如果你正在开发一款垂直领域的数学工具（如函数图像生成、特定几何定理验证等）：

- **几何基础设施**：直接调用大角几何的渲染与计算能力，无需从零开发几何约束求解器，将精力集中在核心业务逻辑的创新上。
