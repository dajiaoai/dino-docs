# 免费使用说明

本文档说明大角几何内容的免费使用范围、适用条件与限制边界。

本说明旨在帮助教师、教研团队、内容创作者、学校、培训机构及其他使用方判断其使用方式是否属于免费范围。本文档用于说明当前开放策略，不构成正式法律协议。若涉及程序化控制、私有内容接入、品牌定制或其他深度集成能力，请参见 [商业许可说明](./COMMERCIAL_LICENSE)。

## 一、核心判断原则

符合以下任一情况，通常可以免费使用：

- 保留大角几何品牌、域名与默认 UI 的内容嵌入链接，通常可直接免费使用
- 产品本身免费，且希望使用开放能力或通过 SDK 接入的，可联系我们申请《免费非商用许可》

您的课件、课程、讲义或内容成品是否收费，并不是判断是否可免费使用的唯一标准。更关键的是您的使用方式是否仍属于品牌保留的内容嵌入，或是否已获得相应授权。

如果您的使用方式涉及程序化控制、品牌定制、批量自动化、企业级权益，或超出免费授权范围，通常需要进一步评估商业许可。

## 二、通常可免费使用的场景

在符合本说明全部条件的前提下，以下场景通常可免费使用：

- 教师将几何内容嵌入 PPT、课件、讲义、课堂演示页
- 学校或培训机构在课程资料页、录播课页面、教学内容页中嵌入几何内容
- 内容团队在博客、专栏、知识库、公开资料页或付费内容页面中展示几何内容
- 在文章、演示文稿、课程内容、教学产品配套材料中引用内容链接
- 使用大角几何默认页面、默认品牌露出与默认交互界面

## 三、免费使用条件

免费使用需同时满足以下条件：

- 使用方式为直接嵌入链接，不通过代码对内嵌内容进行程序化控制
- 保留大角几何域名、默认品牌标识与默认 UI
- 不涉及批量生成、批量调用、自动化处理或服务端任务驱动

## 四、免费使用不包含的能力

免费使用不包含以下能力或权益：

- 通过 SDK 调用内嵌页能力
- 通过协议、脚本、消息通信或其他方式控制内嵌页
- 动态加载或切换分享内容
- 批量生成、批量渲染、批量任务处理或自动化调用
- AI Agent、脚本、服务端任务对画板的自动操作
- 去品牌、白标、品牌定制或界面定制
- 企业支持、专属 SLA、稳定性承诺、资源保障或调用配额

如果您的产品本身免费，且希望使用我们的开放能力或通过 SDK 接入，可联系我们申请《免费非商用许可》。在获得授权后，可按授权范围使用相关能力。

## 五、一个简单判断原则

如果您只是将一个内容页以嵌入链接的方式展示在网页、PPT、课件、讲义、课程页面或其他内容页面中，且保留大角几何默认页面与品牌信息，通常可免费使用，即使这些内容本身是收费的。

如果您的使用方式涉及产品化能力集成、代码控制、自动化调用、私有内容、品牌定制，或企业级保障诉求，通常需要商业许可。

## 六、典型示例

- 商业产品希望隐藏大角几何品牌或以自有品牌方式呈现

如您的产品本身免费，且希望通过 SDK 或其他开放能力接入，请先联系我们评估是否适合申请《免费非商用许可》。
