# 如何充值

登录[开放平台控制台](https://open.dajiaoai.com/console/dashboard)，进入「充值订购」，选择直接充值或资源包并使用微信支付。支付成功后，点数会自动发放，你可以在「订单管理」中查看到账状态。

## 充值步骤

1. 登录或注册[开放平台控制台](https://open.dajiaoai.com/console/dashboard)。
2. 在左侧导航中选择「**充值订购**」。
3. 选择直接充值或资源包，确认金额和到账点数后提交订单。
4. 使用微信扫描支付二维码并完成付款。
5. 在「**订单管理**」中确认订单状态为「已到账」。

点数归属于公司或团队，同一主体下的 API、MCP 调用共用一个点数账户。

## 选择直接充值

直接充值按 `1 元 = 10,000 点` 计算，20 元起充。

充值获得的永久点数在到账后长期有效，适合临时补点和低频调用。账户中同时存在资源包点数时，系统会先使用资源包点数，再使用永久点数。

## 点数使用规则

- 兑换基准为 `1 元 = 10,000 点`，资源包会在此基础上赠送额外点数。
- API 与 MCP 共用点数账户，并按实际调用消耗扣除。
- 有多个资源包时，系统优先使用最早到期的资源包。
- 资源包点数用尽后，系统会继续使用账户中长期有效的永久点数。
- 资源包到期后，未使用的点数将停止抵扣，请根据实际用量选择规格。

永久点数不依附于资源包、长期有效，可通过直接充值、商务约定、活动或补偿获得。

## 退款政策

目前不提供自助退款入口。如需退款，请联系人工客服提交申请。

### 资源包退款

- 资源包仅在**有效期内**支持申请退款；到期后不再受理。
- 退款金额按资源包的未使用现金价值计算：

  `退款金额 = 订单实付款 - 已使用点数对应的现金价值`

- 折扣、倍率或活动赠送的点数不具有独立现金价值，不折算为退款金额。
- 若已使用的现金价值达到订单实付款，可退款金额为 0。
- 0 元活动、补偿或赠送资源包不支持退款。

### 永久点数退款

- 付费充值获得的永久点数，可按订单中的未使用额度申请退款。
- 退款金额按订单实付款扣除已使用额度计算：

  `退款金额 = 订单实付款 - 已使用额度`

- 若订单额度已全部使用，则可退款金额为 0。
- 通过活动、补偿或商务赠送获得的永久点数不具有现金价值，不支持退款。

人工客服会根据订单实付款、点数使用情况及资源包有效期核算最终退款金额。申请时请提供**账号主体、订单号和退款原因**。
