# 模型说明

大角几何智能生图目前提供两个模型版本，均针对几何题图生成场景深度优化。

## 技术实现

大角几何模型基于 Harness Agent 机制构建，能够理解数学题目语义、准确绘制几何约束关系，并编排顶点拖拽、轨迹追踪等动态交互效果。生成产物为可交互的大角几何工程文件（`.algeo`），而非静态图片。

## 模型版本

| 模型 | 定位 | 推荐场景 |
| --- | --- | --- |
| `dinogeo-1` | 标准版，优先控制成本与吞吐 | 常规初高中几何题图、题库批量生产、AI 课件配图 |
| `dinogeo-1-pro` | 专业版，优先生成质量与复杂题稳定性 | 复杂综合题、图片参考还原、证明题配图、高价值题库 |

计费规则见 [API 计费说明](/api/pricing)。

## 能力对比

以下数据来自大角几何内部评测集，测试集覆盖初高中几何题图约 2000 道，复杂综合题与证明题约 500 道。

| 评测维度 | `dinogeo-1` | `dinogeo-1-pro` |
| --- | --- | --- |
| 标准几何题一次通过率 | 95% | 97% |
| 复杂综合题一次通过率 | 79% | 89% |
| 图片参考还原准确度 | 83% | 93% |
| 平均生成耗时 | 30.26 秒 | 51.64 秒 |
