# SDK 2.4.2-beta 概览

`2.4.2-beta` 是当前主推的新版本文档分支，对外重点覆盖新版嵌入能力与更清晰的模式划分。

## 阅读建议

1. 从 [快速开始](./getting-started) 跑通最小示例。
2. 按接入目标选择 [演示模式](./presentation) 或 [编辑模式](./editor)。
3. 需要查看数据格式、消息类型与错误语义时，阅读 [数据协议](./protocol) 和 [事件参考](./events-and-errors)。

## 当前定位

| 模块           | 状态       | 说明                                                        |
| -------------- | ---------- | ----------------------------------------------------------- |
| 演示模式       | 已生产可用 | 支持分享加载、文件注入、切页与 REPL 指令交互                |
| 编辑模式       | 邀测中     | 支持基础画布编辑，深度 UI 自定义与 API 联动持续对齐中       |
| 事件与历史能力 | 逐步对齐   | `ready` / `save` 等核心事件已可用，历史回退等能力持续完善中 |
