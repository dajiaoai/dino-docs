# SDK 文档中心

大角几何 SDK 是为开发者提供的嵌入式几何交互解决方案。通过 SDK，您可以快速将强大的几何演示、编辑与计算能力集成到您的 Web 应用、教学系统或 AI 助手中。

## 核心价值

- **极简集成**：支持 `npm` 安装与 `CDN` 引入，最快 10 分钟即可完成基础画板嵌入。
- **双重模式**：提供面向内容分发的“演示模式”与面向内容生产的“编辑模式”。
- **程序化能力**：详尽的 API 接口与强大的 REPL 指令集，支持通过 JavaScript 或 AI 指令深度控制画板。
- **跨平台兼容**：基于标准 `postMessage` 协议，兼容所有主流 Web 容器。

## 版本体系

我们目前同时维护两个版本分支，建议根据您的集成深度进行选择：

| 版本支线                                       | 定位           | 适用场景                                                           |
| :--------------------------------------------- | :------------- | :----------------------------------------------------------------- |
| [**2.4.2-beta**](./2.4.2-beta/getting-started) | **主推功能版** | 新集成项目；需要使用编辑模式、深度 UI 自定义或更细粒度的画板管理。 |
| [**1.2.1**](./1.2.1/getting-started)           | **兼容参考版** | 存量项目维护；仅需基础演示、切页与简单的内容加载场景。             |
