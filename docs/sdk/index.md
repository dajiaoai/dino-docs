# SDK 文档中心

大角几何 SDK 是为开发者提供的嵌入式几何交互解决方案。通过 SDK，您可以快速将强大的几何演示、编辑与计算能力集成到您的 Web 应用、教学系统或 AI 助手中。

::: tip 在线体验
前往 [示例中心](https://dajiaoai.github.io/algeo-sdk/) 查看 SDK 的实际运行效果与接入示例。
:::

## 核心价值

- **极简集成**：支持通过 `npm` 安装，最快 10 分钟即可完成基础画板嵌入。
- **双重模式**：提供面向内容分发的“演示模式”与面向内容生产的“编辑模式”。
- **程序化能力**：详尽的 API 接口与强大的 REPL 指令集，支持通过 JavaScript 或 AI 指令深度控制画板。
- **跨平台兼容**：基于标准 `postMessage` 协议，兼容所有主流 Web 容器。

## 版本体系

我们当前对外提供两个稳定入口，建议按接入目标选择：

| 版本入口                             | 定位           | 适用场景                                                              |
| :----------------------------------- | :------------- | :-------------------------------------------------------------------- |
| [**2.x**](./2/getting-started)       | **主推功能版** | 新集成项目；默认跟随最新 2.x 能力，适合需要编辑模式和深度定制的场景。 |
| [**1.2.1**](./1.2.1/getting-started) | **兼容参考版** | 存量项目维护；仅需基础演示、切页与简单的内容加载场景。                |

## 文档指引

1. **快速上手**：如果您是第一次接触，请直接阅读 [2.x / 快速开始](./2/getting-started)。
2. **深度控制**：对于需要自动化绘图或 AI 交互的场景，请查阅 [REPL 能力](/sdk/repl)。
