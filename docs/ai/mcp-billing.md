# MCP 计费说明

本文档说明大角几何 MCP 当前的计费规则。

## 计费规则

| 场景             | 计费规则     | 说明               |
| :--------------- | :----------- | :----------------- |
| 调用 MCP Server  | `1` 计费点   | 基础计费           |
| 调用生成图片能力 | `100` 计费点 | 在基础计费之外叠加 |
| 调用导出文件能力 | `1` 计费点   | 在基础计费之外叠加 |
| 其他 tool 能力   | `0` 计费点   | 不额外收费         |

## 典型计费示例

| 调用类型           | 基础计费 | 额外计费 | 合计         |
| :----------------- | :------- | :------- | :----------- |
| 一次普通 MCP 调用  | `1`      | `0`      | `1` 计费点   |
| 一次生成图片的对话 | `1`      | `100`    | `101` 计费点 |
| 一次导出文件的对话 | `1`      | `1`      | `2` 计费点   |

## 如何充值

当前兑换比例为 `1` 元 = `10000` 计费点。当前采用添加微信后手动充值的方式，如需充值，可扫码联系。

![微信充值二维码](https://dl.easeplay.vip/algeo/685b4c2009d5753784ebe7df/841edf50-screenshot-20260525-175003.png)

## 当前范围说明

- 图片生成计费适用于 `export_image`
- 文件导出计费适用于 `export_project`
- `algeo_repl`、`import_project` 等其他能力当前为 `0` 计费点，不额外收费

如计费规则后续有调整，将以控制台、平台公告或最新文档说明为准。
