# AI 接入

AI 接入面向已经具备大模型、Agent、Copilot 或自动化工作流能力的产品与团队。它的目标不是把几何画板嵌入到你的前端页面，而是让 AI 可以直接调用大角几何能力，在对话、推理和自动执行流程中完成作图、导出和项目读写。

如果你想让 AI 在讲题、解题、演示或自动化内容处理中直接操作几何对象，这一部分就是重点。

## 适合什么场景

- AI Tutor 或讲题助手在推理过程中同步作图
- Agent 工作流中自动生成几何图、导出图片或导出项目文件
- 面向 VS Code、Cursor、Claude Code、Codex、WorkBuddy 等 AI 客户端的工具接入
- 需要把几何能力作为 AI 工具链的一部分，而不是传统前端 SDK 的一部分

## 如何选择阅读路径

如果你是第一次接入，建议按下面顺序阅读：

1. 先看 [MCP 接入](./mcp)，了解认证方式、客户端配置和可用能力。
2. 再看 [安装大角几何 Skill](./skill)，让 Agent 更准确地使用 MCP 工具。
3. 如需统一 AI 作图风格，再看 [在 MCP 中使用母版](./master-template)。
4. 最后查看 [MCP 计费说明](./mcp-billing)，确认调用成本与充值方式。

## 当前接入方式说明

### MCP

MCP 是当前已经开放、也是最完整的 AI 接入方式。适合支持远程 MCP 的客户端和 Agent 运行环境，通过标准协议把大角几何能力暴露为可调用工具。

### Skills

大角几何 Skill 为 Agent 提供 MCP 工具说明、作图规则和常用操作流程。推荐通过专为中国用户优化的第三方 Skills 社区 SkillHub 安装，详情请参阅[安装大角几何 Skill](./skill)。

### CLI

CLI 相关文档暂未开放，后续会补充命令行场景下的调用方式与自动化接入说明。

## 与 SDK 接入的区别

AI 接入强调让模型或 Agent 直接调用几何能力；SDK 接入强调由你的前端或业务系统自行控制画板生命周期、事件和数据流。如果你的核心目标是“让 AI 能用”，优先看 AI 接入；如果你的核心目标是“把画板嵌进自己的产品界面”，优先查看<a href="/sdk/" target="_blank" rel="noreferrer">SDK 接入</a>。
