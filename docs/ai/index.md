# AI 接入

本部分面向已有大模型、Agent、Copilot 或自动化工作流的产品与团队。通过 MCP，AI 可以在对话、推理和自动执行流程中直接创建、修改、查询和导出几何图形。

## 适合什么场景

- AI Tutor 或讲题助手在推理过程中同步作图
- Agent 工作流自动生成几何图、导出图片或项目文件
- 在 Codex、Claude Code、Cursor、VS Code、WorkBuddy 等支持远程 MCP 的客户端中使用几何工具

## 推荐接入路径

首次接入请按以下顺序完成：

1. [完成 MCP 授权与连接](./mcp/)。在开放平台创建应用、获取 API Key，并将其作为 Bearer Token 配置到 AI 客户端。
2. 在 MCP 客户端中确认服务已连接，且能够列出大角几何工具；随后即可直接让 AI 作图、查询或导出。
3. 按需[安装大角几何 Skill](./skill/)。Skill 为 Agent 补充工具说明、作图规则和常用流程，推荐安装以提升复杂任务的执行稳定性。
4. 如需保持背景、坐标轴和对象样式一致，再使用 [MCP 母版](./mcp/master-template)。
5. 在上线或评估用量前，查看 [MCP 计费说明](./mcp/billing)。

::: tip
MCP 是让 AI 获得几何操作能力的必需接入；Skill 是在 MCP 已授权、已连接后可选安装的操作知识包。Skill 不提供授权，也不能替代 MCP 服务。
:::
