# 商业许可说明

本文档说明大角几何在公开传播、产品嵌入与商业合作场景下的使用边界。

为鼓励内容传播与生态合作，我们对公开分享内容的直接 iframe 嵌入保持开放；对于程序化控制、私有化接入、品牌定制等深度集成场景，则采用商业许可。

本文档用于说明当前开放策略，不构成正式法律协议。具体授权范围、费用、期限、流量额度与服务承诺，以双方签署的商务合同或书面授权为准。

## 一、免费使用范围

以下场景可免费使用：

- 使用公开分享内容的直接 iframe 嵌入
- 用于网页内容展示、教学展示、博客文章、社区页面、公开资料页等传播场景
- 使用大角几何默认页面、默认品牌露出与默认交互界面

免费使用需同时满足以下条件：

- 嵌入内容为公开分享内容
- 采用直接 iframe 嵌入方式，不通过代码对内嵌页进行程序化控制
- 保留大角几何域名、默认品牌标识与默认 UI
- 不进行白标、去品牌、私有内容加载、批量调用或企业级服务要求

## 二、免费使用不包含的能力

免费使用不包含以下能力或权益：

- 程序化控制内嵌页
- 动态加载或切换分享内容
- 批量生成、批量调用或自动化处理
- AI Agent、脚本、服务端任务对画板的自动操作
- 私有内容加载或受控内容访问
- 去品牌、白标、自定义品牌呈现
- 专属 SLA、企业支持、稳定性承诺或专属资源保障

## 三、需要商业许可的场景

以下任一场景，通常需要取得商业许可：

- 通过 SDK 调用内嵌页能力
- 通过协议、脚本、消息通信或其他方式程序化控制内嵌页
- 动态加载分享内容、切换画板或远程驱动画板行为
- 批量生成几何内容、批量渲染或批量任务处理
- 在 AI 产品、Agent 工作流、自动解题、自动讲解等场景中调用几何能力
- 加载私有内容、受限内容或面向特定用户的数据
- 需要白标、去品牌、品牌定制或界面定制
- 需要企业支持、服务保障、流量额度或其他商业权益

## 四、一个简单判断原则

如果您只是将一个公开分享页以 iframe 方式展示在网页中，且保留大角几何默认页面与品牌信息，通常可免费使用。

如果您的系统需要通过代码驱动画板、接入更深层的交互能力，或需要私有化、品牌定制、自动化、企业保障等权益，通常需要商业许可。
