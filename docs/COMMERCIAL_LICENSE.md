# 商业许可说明

本文档说明大角几何在公开传播、产品嵌入与商业合作场景下的使用边界。

如果您关注内容链接的直接嵌入、PPT/课件使用边界与免费范围，请先参见 [免费使用说明](./FREE_USE)。

本文档聚焦需要进一步评估授权的场景。对于程序化控制、品牌定制等深度集成场景，通常采用商业许可。

本文档用于说明当前开放策略，不构成正式法律协议。具体授权范围、费用、期限、流量额度与服务承诺，以双方签署的商务合同或书面授权为准。

## 一、需要商业许可的场景

以下任一场景，通常需要取得商业许可：

- 通过 SDK 调用内嵌页能力
- 通过协议、脚本、消息通信或其他方式程序化控制内嵌页
- 动态加载分享内容、切换画板或远程驱动画板行为
- 批量生成几何内容、批量渲染或批量任务处理
- 在 AI 产品、Agent 工作流、自动解题、自动讲解等场景中调用几何能力
- 需要白标、去品牌、品牌定制或界面定制
- 需要企业支持、服务保障、流量额度或其他商业权益

## 二、免费产品的例外说明

如果您的产品本身免费，且希望使用开放能力或通过 SDK 接入，可联系我们申请《免费非商用许可》。是否适用、可用能力范围与授权条件，以双方确认结果为准。

## 三、一个简单判断原则

如果您的使用方式只是保留品牌的内容嵌入，通常应参考 [免费使用说明](./FREE_USE)。

如果您的系统需要通过代码驱动画板、接入更深层的交互能力，或需要私有化、品牌定制、自动化、企业保障等权益，通常需要商业许可。

## 四、典型场景示例

以下场景通常需要商业许可：

- 教学系统通过 SDK 动态加载不同题目的几何画板
- 题库系统通过代码控制翻页、导入文件或执行 REPL 指令
- AI 产品自动调用几何能力生成图形、验证步骤或完成讲解
- 商业产品希望隐藏大角几何品牌或使用自有品牌界面
- 企业客户需要私有内容访问控制、配额保障与服务支持

如果上述产品本身为免费产品，也可先联系我们，评估是否可通过《免费非商用许可》使用相关开放能力。

## 五、商业许可通常包含的权益

根据合作方案，商业许可可覆盖以下一种或多种权益：

- SDK 与程序化控制能力
- 协议级调用能力
- 私有内容接入
- 白标或去品牌
- 品牌与界面定制
- 流量额度与调用配额
- 企业支持与商务服务
