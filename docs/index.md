# 大角几何开放平台

大角几何致力于成为**几何能力基础设施**，通过组件化、API 化、Agent 化的方式，让几何绘图与理解能力嵌入更多产品与系统。数学几何相关能力，找大角几何。

## 文档入口

| 模块     | 目标                                             | 入口                        |
| -------- | ------------------------------------------------ | --------------------------- |
| 指南     | 帮助客户和开发者理解平台能力、合作模式与接入规范 | [进入指南](./guide/)        |
| SDK 接入 | 查询版本能力、示例、API 与协议细节               | [进入 SDK 接入](./sdk/)     |
| 控制台   | 了解开发者应用管理与授权能力当前开放状态         | [查看控制台说明](./console) |
| 联系我们 | 获取商务沟通、社群交流与支持入口                 | [查看联系我们](./CONTACT)   |

## 平台当前开放重点

当前公开能力以 **SDK 接入** 为主，帮助开发者将几何演示与编辑能力嵌入自己的 Web 产品中。面向不同接入深度，大角几何同时提供：

- 面向快速集成的嵌入式接入
- 面向深度合作的商业授权与定制支持
- 面向未来能力扩展的接口服务与 AI 几何方向规划

## 你可能正在找

- 如果你想先判断平台是否适合自己的业务，请从 [指南](./guide/) 开始。
- 如果你已经准备接入并需要查 API、协议或示例，请进入 [SDK 接入](./sdk/)。
- 如果你想了解开发者应用管理和授权入口，请查看 [控制台](./console)。
- 如果你需要商务咨询或加入交流社群，请前往 [联系我们](./CONTACT)。

## 能力方向

| 方向                   | 当前状态 | 说明                                           |
| ---------------------- | -------- | ---------------------------------------------- |
| 几何嵌入 SDK           | 已开放   | 支持嵌入演示与部分编辑能力，提供协议和示例文档 |
