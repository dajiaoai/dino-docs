# Pricing

This document describes the current pricing rules for Dino Geometry APIs.

## Intelligent Image Generation Service

- `POST /api/agent/run` charges on task creation.
- Billing is model-based:
  - `dinogeo-1-pro`: 16000 credits
  - `dinogeo-1`: 11000 credits

> Charges apply only on successful execution.

## Render Service

- `/api/render`, `/api/render-svg`, `/api/render-tikz`
- Current price:
  - `export_image`: 100 credits per call
  - `export_svg`: 100 credits per call
  - `export_tikz`: 100 credits per call

## Notes

- Refer to the console and service announcements for the latest pricing.
- Contact support if you have questions.
