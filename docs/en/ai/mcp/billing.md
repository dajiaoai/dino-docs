# MCP Billing

> **All capabilities are currently at 60% off.** The points shown below reflect the actual charge today.

## Billing rules

| Capability | Current Price | Points Charged |
| --- | --- | --- |
| Basic calls | ¥0.03 / 100 calls | 3 pts / call |
| Image export | ¥3 / 100 calls | 300 pts / call |
| Project-data export | ¥3 / 100 calls | 300 pts / call |

- Charged per successful call.

## How to top up

Sign in to the [Open Platform console](https://open.dajiaoai.com/console/dashboard), open **Top Up**, and choose either a direct top-up or a resource pack. Pay with WeChat Pay.

For complete details about top-ups, point usage, and refunds, see [How to Top Up](../../guide/recharge).
