# Common Standards

This section contains standards shared by the Dino-GSP SDK, API, and MCP. Interpret and pass parameters according to these rules regardless of the integration method.

## Common standards

- [Dino-GSP Project File (.algeo) Protocol](./algeo-file-protocol): versions, canvases, AI conversations, master templates, and metadata in a project file.
- [Size Units and Conversion](./units): the px standard for font sizes, line widths, and other dimensions, including px/pt conversion.
- [Font Support](./fonts): the public font catalog and custom-font integration for the SDK, MCP, and HTTP API.

## Tutorials

- [Consistent Image Export Across Workflows](./consistent-image-export): use the same precise crop window across SDK, MCP, and other export workflows to keep composition and pixel dimensions stable.
