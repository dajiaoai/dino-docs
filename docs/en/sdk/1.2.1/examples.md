# SDK 1.2.1 Examples

The SDK package includes a complete `examples/` directory. In your project you can access the example source code at:

```text
node_modules/@dajiaoai/algeo-sdk/examples/
```

If you have cloned the repository, run the following in the `packages/algeo-sdk` directory:

```bash
npx serve .
```

This lets you preview all examples in your local browser.

You can also browse the examples online: [Examples Site](https://dajiaoai.github.io/algeo-sdk/examples/)

For programmatic canvas control via commands, see [REPL Capabilities](/en/sdk/repl).
