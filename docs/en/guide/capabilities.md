# Capabilities

The public documentation is currently organized around three capability areas:

| Capability Area              | Status          | Best For                                                                             |
| ---------------------------- | --------------- | ------------------------------------------------------------------------------------ |
| Geometry Embed SDK           | Available       | Teams embedding geometry presentation or editing into web products                   |
| Developer Console            | Private preview | Partners who need app management and authorization                                   |
| API Services and AI Geometry | Planned         | Partners exploring rendering, structured generation, or AI-driven geometry workflows |
