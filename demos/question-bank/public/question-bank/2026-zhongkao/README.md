# 2026 经典中考真题示例资源

把 10 道题的生成结果放在这里，题号必须使用三位数：`001` 至 `010`。

| 资源 | 目录 | 文件名 |
| --- | --- | --- |
| 静态结果图 | `images/` | `001.png` … `010.png` |
| 大角工程文件 | `projects/` | `001.json` … `010.json` |

工程文件必须是可由 SDK 加载的 JSON。题目列表里的原题配图仍沿用 CSV 提供的 URL；本目录的 `images/` 是“生成结果”页展示的结果图。

放入资源后，点击“启动批量生成”即可载入对应的本地图片和工程文件。Vite 会将本目录发布为 `/question-bank/2026-zhongkao/`。
